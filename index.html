にゃん訳 🐾

文はそのまま、語尾だけねこ語に。入力文はブラウザの外に出ません。

file:// で開かれています。 この開き方だとモデルのキャッシュが効かず、毎回ダウンロードになったり読み込みに失敗することがあります。 ターミナルで cd ~/nyanyaku && python3 -m http.server 8000 を実行し、http://localhost:8000 を開くことをおすすめします。
このブラウザでは WebGPU が使えません。 ブラウザ内で LLM を動かすには WebGPU が必要です。 macOS なら最新の Chrome / Edge、または Safari 17.4 以降でお試しください。Gemini / Claude API を使う場合は WebGPU は不要です。
